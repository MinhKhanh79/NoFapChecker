# No Fap by Mika 🧘‍♂️✨

Ứng dụng theo dõi hành trình tu luyện bản thân (NoFap) phong cách Tu Tiên/Kiếm Hiệp, tối ưu hóa cho Google Pixel và Android 17.

## ✨ Tính năng nổi bật

- **Linh Đài (Streak Tracker):** Đồng hồ đếm ngược tu vi chính xác đến từng giây với hiệu ứng ngọn lửa bùng cháy.
- **Cảnh Giới (Ranking System):** Hệ thống thăng tiến 11 cấp bậc từ *Phàm Nhân* đến *Thượng Nhân* với thanh EXP và đồng hồ đột phá.
- **Hào Kiệt (Leaderboard Logs):** Lưu lại lịch sử những lần "rớt đài", ghi chép tâm ma để rút kinh nghiệm.
- **Pháp Trận DNS:** Tích hợp bộ lọc DNS (AdGuard, CleanBrowsing hoặc tùy chỉnh) qua **Shizuku** để bảo vệ đạo tâm tuyệt đối.
- **Phòng Thủ Tâm Lý:** Cơ chế đếm ngược 15 giây "tĩnh tâm" kèm trích dẫn sâu sắc trước khi cho phép reset.
- **Material You:** Giao diện Light Mode thanh khiết, tự động thay đổi màu sắc theo hình nền (Dynamic Color) trên các dòng máy Pixel.
- **Haptic Feedback:** Phản hồi rung sắc nét, mô phỏng cảm giác chạm thực thụ.
- **Siêu Tiết Kiệm Pin:** Không chạy ngầm, không tiêu tốn tài nguyên khi đóng app.

## 🛠 Yêu cầu hệ thống

- **Android:** 8.0 (API 26) trở lên (Tối ưu nhất trên Android 14 - 17).
- **Shizuku:** Cần cài đặt và khởi động app [Shizuku](https://shizuku.rikka.app/) để tính năng chặn DNS hoạt động.

## 📦 Hướng dẫn cài đặt & Xuất APK

### Cách 1: Tải bản cài đặt sẵn (Dành cho người dùng)
1. Vào mục **Releases** trên GitHub này.
2. Tải file `app-release.apk` mới nhất.
3. Cài đặt vào điện thoại và cấp quyền qua Shizuku.

### Cách 2: Tự build từ mã nguồn (Dành cho đạo hữu lập trình)
1. Clone dự án: `git clone https://github.com/your-username/NoFapByMika.git`
2. Mở bằng **Android Studio (Ladybug hoặc mới hơn)**.
3. Thực hiện **Gradle Sync**.
4. Để xuất file APK release:
   - Vào menu `Build` > `Generate Signed Bundle / APK...`
   - Chọn `APK` > `Next`.
   - Tạo Keystore mới (nếu chưa có) và điền thông tin.
   - Chọn Build Variant là `release`.
   - Nhấn `Finish`. File APK sẽ nằm ở thư mục `app/release/`.
